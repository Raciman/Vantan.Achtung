## ゲームの目的

車を修理して脱出することが目的です。交換用のタイヤを見つけて、パンクしたタイヤを交換しましょう。
マップ内には、強力な武器を入手できる探索スポットがあります。

## 操作方法

| 操作 | キー・ボタン |
| --- | --- |
| 移動 | W / A / S / D または方向キー |
| ダッシュ | 移動中に左Shiftを押し続ける |
| 照準を合わせる | マウス移動 |
| 武器を構える | マウス右ボタンを押し続ける |
| 射撃 | 武器を構えた状態でマウス左ボタン、またはEnter |
| リロード | R |
| 武器の選択・切り替え | 1 / 2 |
| 武器をしまう | 選択中の武器と同じ数字キーをもう一度押す |
| 武器を捨てる | G |
| インタラクト（拾う・調べるなど） | E |
| ポーズメニューを開く・閉じる | Esc |

※ リロード、インタラクト、武器を捨てる操作は、マウス右ボタンを離してから行ってください。
